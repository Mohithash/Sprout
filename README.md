# Sprout

**Keep them alive.** A bring‑your‑own‑key AI plant‑care companion.

- 📷 **Identify** — snap a plant (or describe it) → species, confidence, and a care plan: watering interval and how to check, light, humidity, temperature, feeding, toxicity, tips.
- 💧 **Watering schedule** — every plant on a wavy countdown; "Water all" for thirsty ones; adjustable interval.
- 🩺 **Plant doctor** — photo + symptoms → likely issue, ranked causes, step‑by‑step fix, urgency, prevention.
- 💬 **Ask the expert** — propagation, repotting, pests, anything.
- 📓 **Care log** — watering, feeding, notes and diagnoses per plant.

BYOK: Claude (Anthropic) or any OpenAI‑compatible endpoint. See [PRIVACY.md](PRIVACY.md).

Jetpack Compose · Material 3 Expressive · Room · AGP 9.4. `./gradlew :app:assembleRelease`
